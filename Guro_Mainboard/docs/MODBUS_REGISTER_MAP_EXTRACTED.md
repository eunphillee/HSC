**FC03 policy (upstream_slave_h2tech.c):**

- **start=2000, count=14** → registers 2000..2013 (per-port current + reserved).
- **start=2100, count=1** → register 2100 (DI only).
- **start=2100, count=2** → registers 2100, 2101 (DI + DO).
- **start=2110, count=2** → registers 2110, 2111 (temp, RH).
- **start=2110, count=3** → registers 2110, 2111, 2112 (temp, RH, error_flags).
- **start=2113, count=2** → registers 2113, 2114 (RCC CSR 32-bit).
- **start=2122, count=1** → register 2122 (PC_LED_IN, read-only).
- Any other start or count for these blocks → **0x03 Illegal Data Value**.
- Any other start address (e.g. 2102, 2115, 2123, 3000) → **0x02 Illegal Data Address**.

**FC06:** Accepted addresses: **2101** (DO bitmap), **2120** (PC_ON_EN), **2121** (PC_RESET_EN). Value bits 0..3 for 2101; for 2120/2121 value≠0 → 100ms pulse, 0 → LOW. Write to 2100 or 2122 (read-only) → **0x03 Illegal Data Value**. Any other address → **0x02 Illegal Data Address**.

## 5. SHTC3 Sensor Data and Exposed Registers

**Where SHTC3 is written into aggregated status:**

- **File:** `Application/Src/aggregator.c`
- **Logic:** About every 1 s, `SHTC3_Measure(&hi2c1, &t, &rh)` is called. On success:
  - `out->env_temp_cx10 = (int16_t)(t * 10.0f)`
  - `out->env_rh_x10 = (uint16_t)(rh * 10.0f)`
  - `out->error_flags` has AGG_ERR_SHTC3 cleared.
- On failure:
  - `out->env_temp_cx10 = -32768`, `out->env_rh_x10 = 0xFFFF`, and `out->error_flags |= AGG_ERR_SHTC3`.

**Modbus registers exposing SHTC3:**

| Address | Name | Description |
|---------|------|-------------|
| 2110 | ENV_TEMP_CX10 | Temperature ×10 (°C), signed; -32768 = error |
| 2111 | ENV_RH_X10 | Humidity ×10 (%), 0xFFFF = error |
| 2112 | ERROR_FLAGS | Bit 2 = AGG_ERR_SHTC3 (sensor error) |

These are returned by **FC03** with start=2110 and count=2 or 3 (see above).

## 6. PC_ON_EN, PC_RESET_EN, PC_LED_IN in the Code

**Modbus mapping (as of current firmware):**

- **4x2120 (PC_ON_EN):** FC06 write. value=1 → `Gateway_Action_StartPulsePC_ON_EN()` (100ms HIGH on PC1); value=0 → `BSP_WritePC_ON_EN(0)`. Implemented in `upstream_slave_h2tech.c` and `gateway_actions.c`.
- **4x2121 (PC_RESET_EN):** FC06 write. value=1 → `Gateway_Action_StartPulsePC_RESET_EN()` (100ms HIGH on PC0); value=0 → `BSP_WritePC_RESET_EN(0)`.
- **4x2122 (PC_LED_IN):** FC03 read, count=1. Returns `BSP_ReadPC_LED_IN()` (0=OFF, 1=ON) from PC2.

BSP APIs: **BSP/Inc/bsp_gpio.h**, **BSP/Src/bsp_gpio.c**. Pulse timing is driven by `Gateway_Action_Update()` in the main loop (100ms then drive LOW).
