# Mainboard Modbus 1차 체크리스트

## 0. 기본 연결
- [ ] Slave ID = 1
- [ ] Baud = 9600, 8N1
- [ ] RS485 DE/RE 정상

## 1. FC02 입력 상태
- [ ] `1x0821~` 읽기 응답 확인
- [ ] 자동문 센서/외부 스위치 bit 변화 반영 확인

## 2. FC05 단일 Coil 제어
- [ ] `1x0892` ON/OFF 쓰기
- [ ] 실제 하드웨어/하위보드 동작 확인
- [ ] 실패 시 0x04 또는 알람 비트 반영 확인

## 3. FC01 Coil 상태 읽기
- [ ] `1x0892~0910` 읽기
- [ ] 하위보드 coil 상태와 일치 확인

## 4. FC15 다중 Coil 쓰기
- [ ] 인접 coil 다중 쓰기
- [ ] 부분 실패 시 예외 반환 확인

## 5. FC04 진단값 읽기
- [ ] `4x4000~4011` 읽기
- [ ] hpsb/lpsb online, ADC, alarm bitmask 값 확인

## 6. FC03/06/16 레지스터 동작
- [ ] 4x2100/2101 읽기 및 2101 쓰기
- [ ] 4x3000(slave id), 3001(baud code), 3002(factory reset) 동작 확인

## 7. 예외 응답
- [ ] 미지원 FC -> 0x01
- [ ] 잘못된 주소 -> 0x02
- [ ] 잘못된 값 -> 0x03
- [ ] 내부 실패 -> 0x04

## 8. 회귀 확인
- [ ] 기존 HPSB/LPSB 개별 테스트 기능 유지
- [ ] PC Tool 로그에서 TX/RX/RAW frame 확인
